# APM — 照片管理与外部 AI 接口

APM 提供 Android 相册和 Python 命令行。照片目录、标注和搜索索引保存在本地；模型推理通过用户配置的外部 API 完成。仓库不包含模型权重、推理运行库、模型下载或服务部署代码。

使用说明、API 配置、Python CLI 和构建验证详见 [使用与开发文档](docs/README.md)。
