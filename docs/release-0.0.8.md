# APM 0.0.8

2026-11-04，Android 版本 **0.0.8（versionCode 10）**。

## 更新

- API 设置默认展示已保存的配置列表，顶部固定显示“新增 API”。每条右侧提供“编辑”和“启用”，当前配置显示“已启用”。
- 新增与编辑使用独立表单，保存成功后返回列表。保留地址、模型、密钥、传输许可、测试连接和推荐模型；未保存时返回可继续编辑或明确放弃。
- 旋转和 Dock 页面切换保留草稿及连接测试状态，隐藏的编辑页不会截获其他页面的返回键。
- 包含此前未单独发布的 0.0.7 功能：多套命名 API 配置独立加密保存，显式切换，下次任务使用新配置，进行中的任务继续使用原配置。
- 点击照片右下角绿勾可查看完整历史标注，以及保存的模型、提示词版本和时间；普通照片点击仍打开查看器。

## 验证与升级

- 2026-11-03 完成 Promise、23 项 Python 测试、43 项 JVM 测试和 33 项模拟器回归；Android lint 0 错误、7 条警告、2 条信息。
- 发布时复核生产代码与验收记录的哈希一致，APK 与已测试原件逐字节一致，签名、版本和 API-only 检查通过；沿用同一份已验证 APK。
- 包名仍为 `com.jinof.apm`，继续使用原 debug 签名。SQLite 保持 schema 8，保留照片目录、历史标注与加密 API 配置；Python CLI 保持 0.0.5。
- 本轮没有已连接真机，未进行真机升级验证。已安装同包应用的手机可通过 `adb install -r` 保留数据更新。

完整记录见 [0.0.8 验收记录](roadmap-0.0.8-validation.md)。
