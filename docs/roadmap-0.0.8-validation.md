# Roadmap 0.0.8 验收记录

2026-11-03。Android 为 **0.0.8（10）**，包名保持 `com.jinof.apm`；Python CLI 仍为 0.0.5，SQLite 仍为 schema 8。

## API 列表与编辑

设置页默认只显示已保存的 API 列表，顶部固定放置“新增 API”和当前配置。条目展示名称、地址、模型及传输许可，右侧提供“编辑”和“启用”；当前条目显示不可重复点击的“已启用”。列表不展示密钥，长名称和地址省略显示，多条配置可以滚动浏览。

新增／编辑进入独立表单，保留配置名称、地址、模型、遮罩密钥、传输许可、测试连接、推荐模型与删除入口。保存成功后返回列表；编辑或保存其他配置不会切换当前 API，需明确点击“启用”。新配置不继承密钥和许可，当前配置不可直接删除。

编辑页的顶部返回按钮和系统返回先回到列表。存在未保存草稿时，可继续编辑或明确放弃，取消和校验失败不改写已保存配置。旋转和 Dock 切换保留编辑页及草稿；设置页隐藏后不会截获其他页面的返回键。连接测试期间锁定表单、保存和返回列表，配置重建不会重复发送请求。

复用原有加密配置格式与存储接口，没有数据库迁移。启用仅影响下一次标注或 Agent 搜索，进行中的任务继续使用原配置。保存、启用和浏览列表均不发送请求。

仪器测试仅在 API 35 只读模拟器 `emulator-5562` 上执行。测试使用本地 mock HTTP 服务与生成图片，没有调用 xspark 或 Funnel，也没有上传私人照片；不据此判断外部模型的速度、质量或当前可达性。配置重建通过 `ActivityScenario.recreate()` 验证。
