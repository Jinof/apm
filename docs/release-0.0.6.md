# APM 0.0.6

## 更新

- 重新打开应用时清空“标注所选”，避免误用上次选择；切后台、配置重建、页面切换和查看器返回仍保留本次选择。
- 已标注照片右下角显示绿色勾；正在处理的照片显示旋转圆圈，成功后切回绿色勾，失败保留原有标注状态。
- 全量标注改为任务卡片，展示当前图片、处理阶段、成功／失败／跳过数量、累计耗时、ETA 和最近日志；所选标注也使用同一进度展示。
- ETA 根据本次实际耗时估算，扫描和首张完成前显示等待说明；日志不展示密钥、原始 API 响应或异常原文。

标注任务进度保存在内存中。退出或更新应用后，点击“开始全量标注”会跳过已有当前模型及提示词标注，继续处理剩余照片。

## 验证与升级

- Promise、23 项 Python 测试、43 项 JVM 测试及隔离 Android 构建通过，lint 无错误、8 条原有警告。
- 功能验收的 13 项模拟器回归通过，覆盖进度卡片、旋转标记、受控慢 API、选择会话、相册导航和查看器。发布时复核构建与交付件的非签名 ZIP 内容一致，沿用同一份已验证 APK。
- 已在小米真机通过同包 `adb install -r` 验证。原有标注逐行保留，其他表、加密 API 设置和首次安装时间保持不变；SQLite schema 8，`quick_check=ok`。
- APK 继续只通过外部 API 推理，不含模型权重或推理运行库。Python CLI 保持 0.0.5，本次版本更新针对 Android。

完整记录见 [0.0.6 验收记录](roadmap-0.0.6-validation.md)。
