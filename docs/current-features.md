# 当前功能与数据边界

适用版本：APM 0.0.5。

- **相册**：只读扫描、按拍摄日期浏览、日／周／月热力图、原始分辨率查看。SHA-256 仅用于目录内的内容标识，避免同一内容重复入库。
- **标注**：外部多模态 API 生成中文描述、标签、可见文字和结构化属性，包括物体数量、天色、场景与动作。
- **搜索**：SQLite 本地检索；Agent 将自然语言转换成最多四个只读本地搜索条件。
- **API 设置**：一个多模态模型卡片，供标注和 Agent 共用。

底部页面为“相册、热力图、Agent、设置”。没有人物／宠物管理、相似检查、重复照片检测或视觉特征 API 入口。描述照片中的人、动物和动作仍然可用，但不会注册或识别具体身份。

原照片不会被修改、移动或删除。断网时可浏览已有相册和索引；API 失败或返回不合格结果时保留旧数据。旧版身份、模板、向量、标注与加密设置保留在本机，历史标注中的标签仍可读取，不再执行识别或向量更新。系统边界见 [apm.promise](../apm.promise)。
