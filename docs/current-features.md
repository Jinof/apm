# 当前功能与数据边界

适用版本：Android APM 0.0.7；Python CLI 0.0.5。

- **相册**：只读扫描、按拍摄日期浏览、日／周／月热力图、原始分辨率查看。SHA-256 仅用于目录内的内容标识，避免同一内容重复入库。
- **标注**：外部多模态 API 生成中文描述、标签、可见文字和结构化属性，包括物体数量、天色、场景与动作。
- **搜索**：SQLite 本地检索；Agent 将自然语言转换成最多四个只读本地搜索条件。
- **API 设置**：保存多套命名配置，每套独立保存地址、模型、密钥和传输许可，手动选择一套供标注和 Agent 共用。新配置默认留空且未许可；保存不会自动切换。

底部页面为“相册、热力图、Agent、设置”。没有人物／宠物管理、相似检查、重复照片检测或视觉特征 API 入口。描述照片中的人、动物和动作仍然可用，但不会注册或识别具体身份。

原照片不会被修改、移动或删除。断网时可浏览已有相册和索引；API 失败或返回不合格结果时保留旧数据。旧版身份、模板、向量、标注与加密设置保留在本机，历史标注中的标签仍可读取，不再执行识别或向量更新。系统边界见 [apm.promise](../apm.promise)。

“标注所选”只保留本次会话的选择。首页按系统返回退出、从最近任务划掉或进程重启后，再次打开显示 0；Home 键切后台、旋转屏幕、切换底部页面和从查看器返回仍保留选择。选图成功会替换当前范围，取消则保持原样。清空只涉及 `annotation_selection` 表，不删除照片目录、历史标注或授权，不改动 API 设置，数据库版本仍为 8。

相册的缩略图与详情图片右下角会显示绿色勾，表示本地已有保存的标注；本地搜索结果缩略图也使用相同标记。绿色勾不表示当前选中，也不要求标注来自当前配置的模型。未标注的照片不显示，标注成功后刷新显示，重新标注失败时保留已有标记。标记只叠加在界面上，不修改原图。点击绿勾可查看该照片已保存的完整描述、标签、OCR、结构化属性和模型／提示词版本／时间，历史身份标签与主体描述也保留显示。缺失来源信息显示“未记录”。详情可滚动和选择文字，不发起 API 请求、不写数据库；点击照片其他区域仍打开查看器。

标注进行时，当前处理照片右下角显示旋转圆圈，优先于绿色勾；成功写入后立即恢复绿色勾，失败则保留原有已标注状态。“全量标注”以任务卡片呈现，也显示所选标注任务的进度：当前文件、成功／失败／跳过数量、累计耗时、ETA 和最近五条阶段日志。扫描阶段和首张完成前暂不估算；之后按已完成请求的平均耗时估算剩余待处理队列，不把跳过的照片计入工作量。日志只保留本次运行的最近 40 条，不持久化、不包含密钥或原始响应。

任务进度为当前运行的内存状态，退出或更新应用后不自动恢复任务；再次点击“开始全量标注”会按当前模型和提示词跳过已完成图片，处理剩余图片。
