# Roadmap 0.5.0 相册与搜索验收

Android APM 0.5.0（versionCode 16），2026-11-21。

## 相册与搜索结果

相册每行五张照片，第六张从下一行左侧开始。缩略图按实际格宽请求。页头和滚动中的日期继续跟随照片顺序。[五列相册截图](assets/roadmap-0.5.0/album.png)

相册关键词搜索和 Agent 搜索共用结果布局。每行左侧是一张缩略图，右侧显示完整标签和分类。分类取自已有标注中的天色、天空、物体、人物外观、动作、场景和天气。文字按可用宽度换行，卡片随内容增高。点照片打开原图，点绿勾可查阅完整描述、OCR 和标注来源。[“咖啡”的两张搜索结果](assets/roadmap-0.5.0/search-results.png)

## 全部标签

点相册搜索框内、提交放大镜左侧的“全部标签”，浮框会显示整个可访问相册的标签及照片数。每张照片取最新标注，相同标签在一张照片上只计一次，英文字母大小写合并。照片数高的在前，同数按标签文字排序。浮框可纵向滚动，单个标签过长时也会换行。[按照片数排列的标签](assets/roadmap-0.5.0/all-tags.png) · [长标签换行](assets/roadmap-0.5.0/all-tags-wrapped.png)

标签统计按需在后台执行，独立于搜索结果、热力图所选日期和快捷建议的采样上限。关闭浮框会回到原查询。点选标签会把标签填入搜索框并执行本地关键词搜索。

## 验证与交付

- 标签统计测试使用 501 张已标注照片，覆盖同图重复、大小写、同数量排序和第 500 张之后才出现的标签。数据库测试另行核对了多 URI、旧标注及已失去访问权限的照片。
- Android 15 模拟器实测了每行五个格子的坐标、搜索结果中缩略图和文字的位置，以及浮框内长标签的实际行数和末行结尾。模拟器仪器测试 55 项通过，另行通过进程重启前后的选择会话检查。
- Promise 格式、lint 和结构检查通过。55 项 Android JVM 单测和 23 项 Python 测试通过。Android lint 为 0 错误、3 条既有警告。主 APK 和测试 APK 通过 API-only 包检查。
