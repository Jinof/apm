# Roadmap 0.0.9 验收记录

## 启动行为

“让照片，说出自己的故事”移到首次读取本地相册数据的加载界面，配合加载指示器显示。首次读取完成后直接展示首页，不再出现“开始探索／稍后再看”的介绍弹窗。

加载阶段不调用模型 API、不额外请求权限，也不设置固定等待、倒计时或最短展示时间。读取失败时结束加载，在首页沿用本地索引读取错误提示。后台返回、页面切换和查看器返回只刷新原有页面，不重新进入启动加载态。Activity 重建仍会读取初始页面数据，原有 ViewModel 会话规则继续保留选择。

此次只调整启动展示与进入首页的条件，不修改数据库结构、照片授权、历史标注或 API 配置。启动时清空临时标注选择的既有规则继续生效。
