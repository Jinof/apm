# Roadmap 0.6.0 照片墙滑动条

Android APM 0.6.0（versionCode 18），2026-11-21。

## 使用

打开相册，在五列照片墙右侧按住带白色上下箭头的磨砂滑块。往下拖浏览较早的照片，往上拖回到较新的照片。拖到顶部可看见相册页头，拖到底部可看见最后一行。直接滑动网格时，滑块也会跟随滚动位置。按日期筛选后，滑动范围随筛选结果更新。

滑块宽为屏宽的 4%，高为屏高的 8%，宽高各为上一构建的 4 倍。滑块中心距右边 10%，在屏高的 10% 至 80% 之间移动。空墙隐藏滑块，一屏可放下所有内容时滑块停在起点。点缩略图打开单张原图后可用底部箭头翻页，返回相册仍在原来的位置。[照片墙](assets/roadmap-0.6.0/wall.png) · [滑块细节](assets/roadmap-0.6.0/slider-detail.png) · [单张照片页](assets/roadmap-0.6.0/viewer.png)

## 验收

- 243 张照片组成的测试墙覆盖页头、普通滚动、从滑块中心旁起拖以及不足五张的末行。拖过中间行时只铺方框，松手后加载停留位置的缩略图。
- 另行验证了空墙、一屏可放下的短墙、从右向左布局、日期筛选和无障碍进度调节。滑块经过放大镜时，点放大镜可搜索，纵向拖动仍可滚动照片墙。
- 在 1080 × 2400 像素的模拟器上，从应用首页实际浏览了 103 张测试照片。滑块约为 43 × 192 像素，中心从 (972, 240) 到 (972, 1920)。拖到底部看到了最后一张，再用普通手势滚动，滑块随之移动。点开第 53 张后核对了单图页，返回时照片墙和滑块回到打开前的位置。
