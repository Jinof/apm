# Roadmap 0.0.7 验收记录

2026-09-27 完成本地实现与模拟器验收。Android 为 **0.0.7（9）**，包名仍为 `com.jinof.apm`；Python CLI 保持 0.0.5，SQLite 保持 schema 8。

## 多套 API 配置

设置页支持新增、命名、编辑、删除和手动切换配置。每套独立保存地址、模型、密钥和传输许可，配置列表与当前配置 ID 一起使用原有 Android Keystore 加密文件保存。

新配置默认留空且未许可；保存其他配置不会自动切换。当前配置不可直接删除。切换遇到未保存草稿时，可选择继续编辑或明确放弃。草稿及连接测试状态在 Activity 配置重建时保留，密钥不写入实例状态 Bundle；测试期间锁定表单与配置管理。

旧版单份加密配置读取为“默认配置”，只读加载前后文件字节完全相同；首次明确保存或管理配置才写入多配置格式。旧 SharedPreferences 迁移保持原行为。现有 `load()`／`save()` 调用只操作当前配置，不丢失其他配置。

保存、切换和删除均不发起请求。测试连接使用正在编辑的配置和生成图片，每套配置保留推荐模型入口。下一次标注或 Agent 搜索读取当前配置；已开始的任务使用原配置快照。家中使用 xspark 内网地址，外出使用用户自己的 Funnel HTTPS 地址；没有自动选择、自动切换或故障转移。手机上的 `localhost` 指手机本身。

## 已保存标注详情

相册网格、详情卡片和本地搜索结果的绿勾可打开只读详情，显示该照片保存的完整描述、标签、OCR、结构化属性及模型／提示词版本／时间；历史身份标签与主体描述继续可读。没有记录的来源信息显示“未记录”，不会取当前 API 设置补齐。

详情支持滚动和选择文字，打开、关闭不发请求、不写入数据。绿勾点击不打开照片查看器，普通照片点击仍正常打开；标注中的旋转圆圈保持原行为。
